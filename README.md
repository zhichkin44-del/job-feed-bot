# job-feed-bot — сборщик вакансий с отбором и проверенными письмами

Бот собирает вакансии из открытых лент без входа в аккаунты (Хабр Карьера, публичные Telegram-каналы, Hacker News «Who is hiring», Remote OK, We Work Remotely, Remotive, Himalayas, Crypto Jobs List), убирает дубли, оценивает каждую вакансию по правилам вашего профиля, к лучшим готовит короткое письмо и отправляет подборку карточек в Telegram. Письмо собирается **только из утверждённых вами фраз**, а проверка не пропускает в него цифру, которой нет в этих фразах и в названии вакансии, — так бот не придумает опыт, которого у вас нет. Модель для этого не нужна, но проверка подойдёт и для черновиков, написанных моделью.

*EN: A Node.js bot that collects job postings from open feeds (no logins), deduplicates them, scores them against your profile with plain rules, composes a short cover letter from approved phrases only, rejects any letter containing a number that is not in those phrases, and sends a card digest to Telegram. No dependencies. 44 tests. Profile and facts in this repository are a template: fill in your own.*

## Схема

```
открытые ленты ──► collect.js ──► разбор RSS / JSON / HTML-превью (sources.js, sources-en.js)
(Хабр, Telegram,       │
 HN, Remote OK, …)     ▼
                  lib.js: дедупликация, зарплата, оценка 0–100 по profile.js, отсев (продажи, поддержка, разметка…)
                       │              geo.js: язык и регион вакансии
                       ▼
                  digest.js ──► letters.js: письмо из фраз facts.js ──► checkLetter(): цифры, строки, ссылка, самовосхваление
                       │                                                      не прошло — вакансия в подборку не попадает
                       ▼
        data/<дата>.md + .json        data/digest-<дата>.md + digest-<дата>.tg.json
                                                          │
                                           send.js (с флагом --yes) ──► Telegram Bot API
```

## Запуск одной командой

Нужен Node.js 20 или новее, зависимостей нет. Из клона репозитория, без сети и без ключей, на заранее подготовленной ленте вымышленных вакансий:

```bash
npm run sample
```

В папке `data/` появятся отчёт, подборка с письмами и файл сообщений для Telegram. Тот же прогон по живым лентам:

```bash
node src/radar.js --digest
```

Один прогон делает около 43 запросов к 8 открытым источникам с паузой между запросами и честным User-Agent; полный отчёт — `data/<дата>.md`. Ленты hh.ru выключены по умолчанию: robots.txt и соглашение hh запрещают разбор, включать их — на вашу ответственность (`COLLECT_DEFAULTS.hh` в `src/collect.js`).

Отправка в Telegram (токен и чат — только из окружения, `.env.example` без значений):

```bash
node --env-file=.env src/send.js data/digest-<дата>.tg.json          # показать, что уйдёт
node --env-file=.env src/send.js data/digest-<дата>.tg.json --yes    # отправить
```

## Свой профиль

Два файла, оба — шаблоны с примерами:

- `src/profile.js` — какие запросы задавать, какие роли и стек повышают оценку, что отсекается, какие риски понижают оценку (пример: нужен английский, 5+ лет стажа). Правится без изменения логики.
- `src/facts.js` — утверждённые фразы для писем: имя, ссылки на проекты, формулировки по темам вакансий, варианты писем. Квадратные скобки `[…]` замените своим текстом; цифры добавляйте только проверенные. Адрес сайта можно задать переменной `JOB_BOT_SITE`.

Личные данные в репозитории не хранятся: никаких имён, контактов и ключей, токен Telegram читается из окружения.

## Тесты

```bash
npm test
```

Результат запуска 18.11.2026 (Node.js 24, чистая копия репозитория): **44 теста, все прошли**. Сеть в тестах не используется: ленты и Telegram подменены. Покрыто: разбор RSS и JSON лент, зарплаты и валюты, оценка и отсев, язык и регион, экранирование недоверенного текста вакансий, проверка писем, сборка карточек и кнопок, отправка в Telegram (токен не попадает в текст ошибки).

## Ограничения

- Письма собираются из шаблонов и утверждённых фраз, а не пишутся моделью: они короткие и однотипные. Подключить модель можно, прогнав её черновик через `checkLetter()`.
- Профиль и фразы в репозитории — пример. Без их заполнения письма получатся с заглушками в квадратных скобках.
- hh.ru в сборе выключен по умолчанию; публичный API hh без авторизации с апреля 2026 отвечает 403 (проверено 04.11.2026), поэтому русские площадки — Хабр Карьера и Telegram-каналы.
- Список Telegram-каналов и их активность проверялись 06.11.2026 и устаревают; каналы без постов более 14 дней бот отмечает как кандидаты на замену.
- Кнопки «Отправил / Пропустить / Не моё» из подборки требуют приёмника нажатий, которого в пакете нет, поэтому `send.js` отправляет только кнопки-ссылки и «Скопировать текст». Отклик на вакансию бот не отправляет никогда: его отправляете вы.
- Курсы валют для пересчёта зарплат заданы в `src/profile.js` (на 30.10.2026) и не обновляются сами.
- Проверялось на Windows.
